# 04: 메인 화면 — 최신 글과 식당 목록 + 시연용 샘플 데이터

**What to build:** 누구나 `/`에서 최근에 올라온 글 5개와, 평균 별점 순으로 정렬된 식당 목록(20개씩)을 본다. 지역(시/도)을 고르면 그 지역 식당만 보이고, 지역과 페이지 번호가 주소에 반영되어 링크로 공유할 수 있다. 아직 글이 없는 식당은 맨 뒤에 "아직 글 없음"으로 보인다. 정렬을 시연할 수 있도록 명령 하나로 샘플 데이터를 넣는다. 스펙: `.scratch/guestbook/spec.md`.

**Blocked by:** 02 (새 식당과 첫 글을 쓰고 식당 페이지에서 보기)
