# 가입 없이 글 비밀번호로 권한을 확인한다

실기시험 요구사항(퀴즈 5주차)에 따라 회원 가입·로그인과 운영자, 별도 관리되는 식당을 모두 없애고, 글 하나에 이름·식당·지역·별점·메시지를 담는다. 글을 쓸 때 입력한 글 비밀번호(scrypt 해시로만 저장)가 맞을 때만 메시지 수정과 글 삭제를 허용하며, 틀리면 거부하고 화면에 "비밀번호가 일치하지 않습니다."라고 안내한다. 계정이 없으니 글 비밀번호를 잊으면 그 글은 고칠 수 없다.

## Considered Options

- 회원 계정 방식(ADR-0002): 시험 요구사항("별도의 회원가입/로그인 없이")과 맞지 않는다.
- 식당을 별도 대상으로 두고 여러 글을 모으기(ADR-0001): 요구사항 범위를 넘고 시험 시간 안에 끝내기 어렵다. 식당은 글 안의 텍스트로만 남긴다.
