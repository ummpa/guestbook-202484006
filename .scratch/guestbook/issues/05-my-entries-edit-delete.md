# 05: 내 글 관리 — 목록·수정·삭제

**What to build:** 회원은 `/me`에서 자기가 쓴 글을 모아 보고, 자기 글의 별점·본문·추천 메뉴를 `/entries/[id]/edit`에서 수정하거나 확인 창을 거쳐 삭제한다. 수정된 글에는 "수정됨"이 표시되고, 별점 변경은 평균 별점과 목록 순서에 바로 반영된다. 이미 글을 쓴 식당을 글쓰기에서 고르면 새 글 대신 내 기존 글의 수정 화면으로 이동한다. 남의 글은 수정·삭제할 수 없다. 스펙: `.scratch/guestbook/spec.md`.

**Blocked by:** 03 (기존 식당을 검색해서 글 쓰기)

**Status:** wontfix (ADR-0003으로 대체됨)

- [ ] 방명록 모듈이 "회원의 글 목록", "회원이 특정 식당에 쓴 글 조회", "글 수정", "글 삭제"를 제공하며, 요청자(회원 ID)를 받아 작성자 본인인지 모듈 안에서 확인한다
- [ ] `/me`는 로그인 필요, 내 글마다 식당 이름·지역·별점·작성일이 보이고 식당 페이지로 이동할 수 있다
- [ ] 수정은 글쓰기와 같은 입력 규칙을 따르고, 식당은 바꿀 수 없으며, 수정 시각이 기록된다
- [ ] 수정된 글은 식당 페이지에서 "수정됨"으로 표시된다
- [ ] 수정해도 최신 글 순서(작성 시각 기준)는 바뀌지 않는다
- [ ] 삭제는 확인 창을 거치며, 삭제 후 같은 식당에 새 글을 다시 쓸 수 있다
- [ ] 식당의 마지막 글을 지워도 식당은 "아직 글 없음" 상태로 남는다
- [ ] 다른 회원의 글에는 수정·삭제 버튼이 보이지 않고, 남의 글 수정 주소로 직접 들어가거나 수정·삭제를 요청하면 "권한 없음"으로 거절된다
- [ ] `/write`에서 이미 글을 쓴 식당을 고르거나 식당 페이지에서 "글 쓰기"를 누르면 내 기존 글 수정 화면으로 이동한다
- [ ] 방명록 모듈 테스트: 내 글 목록, 수정 후 조회(수정 시각·평균 별점 반영), 수정 검증 실패, 다른 회원의 수정·삭제 거절, 삭제 후 재작성 가능, 마지막 글 삭제 후 식당 남음, 수정해도 최신 글 순서 불변
