# 06: 운영자 — 로그인, 글 삭제, 식당 수정·삭제

**What to build:** 운영자는 `/operator`에서 운영자 비밀번호를 입력해 들어오고, 방문자와 같은 식당 페이지에서 운영자용 버튼으로 아무 글이나 삭제하거나, 식당 정보(이름·지역·상세 주소)를 고치거나, "이 식당의 글 N개도 함께 삭제됩니다" 확인 창을 거쳐 식당을 삭제한다. 운영자는 회원이 아니므로 글을 쓸 수 없고, 남의 글 내용을 고칠 수도 없다. 브라우저를 닫거나 운영자 로그아웃을 하면 운영자 상태가 풀린다. 스펙: `.scratch/guestbook/spec.md` (ADR 0001, 0002).

**Blocked by:** 02 (새 식당과 첫 글을 쓰고 식당 페이지에서 보기)

**Status:** wontfix (ADR-0003으로 대체됨)

- [ ] `/operator`에서 운영자 비밀번호가 맞으면 운영자 쿠키가 발급되고, 틀리면 거절된다
- [ ] 운영자 쿠키는 서버가 서명해 위조할 수 없고, 만료 없는 세션 쿠키라 브라우저를 닫으면 사라진다. 운영자 로그아웃도 있다
- [ ] 방명록 모듈이 운영자용 "글 삭제", "식당 정보 수정", "식당 삭제"를 제공하며, 요청자가 운영자인지 모듈 안에서 확인한다
- [ ] 운영자가 아니면(회원 포함) 세 동작 모두 "권한 없음"으로 거절된다
- [ ] 식당 정보 수정은 새 식당과 같은 입력 규칙을 따른다
- [ ] 식당 삭제 확인 창에 함께 삭제될 글 수가 보이고, 삭제하면 그 식당의 글도 모두 사라진다
- [ ] 운영자 상태에서는 식당 페이지에 운영자용 삭제·수정 버튼이 보이고, 글 수정 버튼은 보이지 않는다
- [ ] 운영자 상태(회원 로그인 없음)에서는 글쓰기가 막힌다
- [ ] 머리글에 운영자 상태 표시가 있다
- [ ] 방명록 모듈 테스트: 운영자의 글 삭제, 회원의 운영자 동작 거절, 식당 정보 수정과 검증 실패, 식당 삭제 시 글 함께 삭제, 삭제된 식당 조회 시 없음
