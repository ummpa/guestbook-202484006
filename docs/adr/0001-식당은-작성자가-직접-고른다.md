# 식당은 작성자가 직접 고른다

글을 쓸 때 작성자가 기존 식당을 검색해 고르고, 없으면 새 식당을 추가한다. 이름·지역 자동 일치나 카카오 장소 검색 API 대신 이 방식을 택한 이유는 수업 과제 범위에서 외부 API 키·연동 없이 식당 중심 구조를 만들기 위해서다. 그 대가로 같은 실제 가게가 두 개의 식당으로 등록될 수 있음을 받아들이며, 잘못 만들어진 식당은 운영자가 정보를 고치거나 삭제해 정리한다(식당 병합 기능은 만들지 않는다).

## Considered Options

- 이름+지역이 정확히 같으면 같은 식당으로 자동 판단: 띄어쓰기·지점명 차이로 쉽게 갈라져 오히려 혼란스럽다.
- 카카오 장소 검색 API: 가장 정확하지만 API 키, 외부 의존, 호출 제한 처리가 필요하다. 나중에 바꾸려면 기존 식당 데이터 이전이 필요하다.
