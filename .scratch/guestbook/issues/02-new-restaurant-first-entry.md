# 02: 새 식당과 첫 글을 쓰고 식당 페이지에서 보기

**What to build:** 회원이 `/write`에서 지역을 고르고 새 식당(이름, 상세 주소)과 첫 글(별점, 본문, 추천 메뉴)을 한 번에 제출하면, 식당과 글이 함께 저장되고 `/restaurants/[id]`로 이동한다. 식당 페이지에서는 누구나(로그인 없이) 식당 이름·지역·상세 주소·평균 별점·글 수와 그 식당의 글 목록(최신순)을 본다. 방명록 모듈의 뼈대가 여기서 생긴다. 스펙: `.scratch/guestbook/spec.md` (ADR 0001).

**Blocked by:** 01 (회원 가입·로그인·로그아웃)

**Status:** wontfix (ADR-0003으로 대체됨)

- [ ] 방명록 모듈이 DB와 현재 시각을 주입받아 만들어지고, "새 식당과 첫 글 쓰기"와 "식당 상세 조회"를 제공한다
- [ ] 식당 입력 검증: 이름 1~50자, 지역은 17개 시/도 중 하나, 상세 주소 0~100자
- [ ] 글 입력 검증: 별점 1~5 정수(필수), 본문 1~1000자, 추천 메뉴 0~50자
- [ ] 모든 문자열은 앞뒤 공백을 자른 뒤 검증하고, 공백뿐인 선택 항목은 없음으로 저장한다
- [ ] 식당과 첫 글은 원자적으로 저장된다: 글 검증이 실패하면 식당도 만들어지지 않는다
- [ ] 실패는 결과 값(성공 여부 + 구체적 실패 사유)으로 돌아오고, 폼은 안내 문구와 함께 입력값을 유지한다
- [ ] 식당 상세는 평균 별점(소수 첫째 자리), 글 수, 글 목록(작성 시각 내림차순)을 돌려준다. 각 글에는 작성자 닉네임·별점·본문·추천 메뉴·작성일이 있다
- [ ] 식당 페이지에 별점이 별 아이콘으로, 작성일이 "2026.09.30" 형식으로 보인다
- [ ] 식당 페이지에 "글 쓰기" 버튼이 있다(식당 미리 선택은 03)
- [ ] 없는 식당 ID는 404 "찾을 수 없는 식당"
- [ ] 비로그인 상태로 `/write`에 들어가면 로그인 화면으로 가고, 로그인 후 `/write`로 돌아온다
- [ ] 방명록 모듈 테스트: 새 식당+첫 글 저장 후 상세 조회 왕복, 식당·글 검증 실패 사유, 글 검증 실패 시 식당이 생기지 않음, 공백 처리, 평균 별점과 글 수, 글 목록 순서, 없는 식당 조회
